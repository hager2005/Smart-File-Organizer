# Smart-File-Organizer
مع الاستخدام اليومي لأجهزة الكمبيوتر، بتتراكم الملفات والمستندات والصور في أماكن مختلفة، وبيكون الوصول لملف معين وسط العدد الكبير من الملفات أمرًا صعبًا وبيستهلك وقت. ومن هنا جاءت فكرة Smart File Organizer، وهو برنامج يهدف إلى تنظيم الملفات تلقائيًا بطريقة تساعد المستخدم على الحفاظ على ترتيب جهازه والوصول إلى ملفاته بسهولة. يساعد البرنامج على تصنيف
